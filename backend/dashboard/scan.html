Submission recovery

Submission IDs are saved on this device before sending. QR codes and passwords are not saved. After a reload, sign in and recover receipts; if nothing was received, rescan the original code to reuse its submission ID. No arrival is backdated.

    A USB scanner must type text and finish with Enter. Keep this field focused. Retry the same code after a connection failure; the submission ID stays the same until you sign out or close this page.

    Camera access starts only when you choose it. One code is captured at a time; choose Use camera again for the next scan. Signing out or hiding the page stops the camera.
